موقع ورشة تحديثات منصة العمل التطوعي — حفظ مباشر في Google Sheets

أولاً: نشر السكربت (من حساب يملك صلاحية تعديل الشيت)
1. افتحي الشيت المطلوب: https://docs.google.com/spreadsheets/d/17eZ89WlyTLX4U-xC2m60N4xF1Sg76KHCWz1VuA0r7ec/edit
2. من «الإضافات» > Apps Script، افتحي مشروعًا جديدًا.
3. استبدلي محتوى Code.gs بمحتوى الملف Code.gs المرفق.
4. أضيفي ملف HTML جديدًا باسم Index (دون كتابة الامتداد في نافذة الإنشاء)، والصقي محتوى Index.html فيه.
5. احفظي. من «نشر» > «عملية نشر جديدة» > «تطبيق ويب»: التنفيذ باسم «أنا»، والوصول «أي شخص». اسمحي بالصلاحيات اللازمة للوصول للشيت.
6. انسخي رابط تطبيق الويب النهائي المنتهي بـ /exec. لا تستخدمي رابط /dev.

ثانيًا: رابط GitHub الحالي (اختياري)
- افتحي الملف index.html الصغير المرفق، واستبدلي النص PASTE_APPS_SCRIPT_WEB_APP_URL_HERE برابط /exec المنسوخ. ثم ارفعي index.html إلى مستودع GitHub بدل الصفحة القديمة. يبقى رابط GitHub نفسه ويفتح الاستبانة داخل الموقع.
- يمكنك استخدام رابط /exec مباشرة إذا لم تكوني بحاجة إلى رابط GitHub.

ثالثًا: التحقق
- سجلي ردًا تجريبيًا من رابط الموقع، ثم افتحي تبويب «ردود النموذج 1» في الشيت. يجب أن يظهر صف جديد فيه جميع الإجابات. رسالة الشكر تظهر فقط بعد نجاح إضافة الصف.
- إذا ظهر خطأ «العمود المطلوب غير موجود»، تأكدي أن صف العناوين في الشيت لم يتغير؛ أرسلي صورة الصف الأول لأضبط مطابقة العناوين.
- إذا عدلتِ Code.gs أو Index.html لاحقًا، افتحي «إدارة عمليات النشر» وحدّثي إصدار تطبيق الويب، ثم أعيدي التجربة.

ملاحظة: التسجيل الجديد يكتب مباشرة إلى الشيت المحدد، ولا يضاف إلى إحصاءات ردود Google Forms. لا تحذفي تبويب الردود أو تغيري عناوينه بعد النشر.
